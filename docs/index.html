每日影视海报

一款运行于 Linux 桌面的影视海报自动生成工具

v1.0 · 微博开放平台客户端

📌应用简介

「每日影视海报」是一款运行在 Linux 桌面环境的自动化工具，对接微博开放平台。 每日从热门影视中精选 9 部作品，自动生成 1080×1600 竖版海报并拼接文案， 通过微博 API 定时发布图文微博。

⚡功能特性

  • 每日自动精选 9 部热门影视作品
  • 自动生成 1080×1600 竖版海报（Python PIL）
  • 自动拼接微博文案（片名、评分、类型）
  • 通过微博开放平台 API 定时发布图文微博
  • 发布失败自动 PushPlus 告警通知

🔧使用流程

生成海报（Python PIL） → 拼文案（Node.js） → 发微博（微博API） → 完成

🛠技术栈

Python 3 Pillow Node.js 微博开放平台 API PushPlus
